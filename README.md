# 视频嗅探下载器 (Video Sniffer Downloader)

Edge / Chrome 通用的网页视频资源嗅探与下载扩展（Manifest V3）。
自动检测页面播放的视频流（HLS / DASH / 直链 / 私有分片），支持切片自动合并、AES-128 自动解密、防盗链处理，下载内容按"视频名/目录"归档保存。

完全免费、无广告、无统计追踪，所有数据处理均在本地完成。

## 功能特性

- **多协议嗅探**：同时监听网络请求与页面媒体元素，播放即发现
- **HLS (m3u8)**：多码率自动选优 → 并发分片下载 → AES-128 自动解密 → 自动合并为单文件（TS/fMP4）
- **DASH 分离流**：视频/音频流分别嗅探下载，附 ffmpeg 无损合并说明
- **防盗链站点**：通过会话规则为下载请求补齐页面 Referer（B 站等）
- **私有分片协议**：爱奇艺字节范围分片自动归一化为整文件直链
- **目录归档**：每部视频一个独立目录，合并文件、分片、合并说明统一存放
- **断点续传**：分片缓存于本地，中断后重试不重复下载
- **批量清晰度选择**：多码率/清晰度分列展示，自选下载

## 站点支持矩阵

| 机制 | 状态 | 说明 |
|------|------|------|
| 标准 HLS (m3u8) | 已支持 | 含 AES-128 加密与 fMP4 |
| 直链视频 (mp4/flv/webm 等) | 已支持 | 浏览器原生下载 |
| 哔哩哔哩 DASH (m4s) | 已支持 | 视频/音频流 + ffmpeg 合并 |
| 爱奇艺免费内容 | 已支持 | 私有分片归一化，单文件即完整视频 |
| 静态 blob 视频数据 | 已支持 | 页面内分块抓取 |
| DRM 加密内容 | 不支持 | 版权保护内容（如会员付费视频）技术上无法且不应被下载 |

> 其它站点遇到无法下载的情况，请通过"反馈与求适配"提交，呼声高的站点将优先适配。

## 使用

1. 打开含视频的网页并**播放视频**（嗅探依赖播放行为）
2. 点击工具栏图标，弹窗中列出检测到的视频资源
3. 按需修改文件名，点击"下载"
4. 下载内容保存于：`浏览器默认下载目录 / 根目录 / 视频名 /`

### 直链（DASH）流合并

DASH 站点的视频流与音频流是两个独立文件。两者下载完成后，按目录内"音视频合并说明.txt"执行一条 ffmpeg 命令即可无损合并：

```
ffmpeg -i "标题-视频流.m4s" -i "标题-音频流.m4s" -c copy "标题.mp4"
```

## 权限说明

| 权限 | 用途 |
|------|------|
| `webRequest` + `<all_urls>` | 嗅探页面播放的视频资源地址 |
| `declarativeNetRequest` | 为下载请求补齐与页面播放一致的 Referer（应对 CDN 防盗链），规则随任务结束即时回收 |
| `downloads` | 将合并后的视频保存到用户指定目录 |
| `storage` | 本地保存任务记录与设置（不上传任何数据） |
| `offscreen` | 在 MV3 环境中完成分片合并与保存 |
| `tabs` / `alarms` | 获取页面标题用于命名；定时恢复中断任务 |
